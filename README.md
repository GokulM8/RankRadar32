# Cynbit GapLens

> See the content your competitors cover and you don't.

GapLens is an AI content-gap and opportunity engine for SEO services. It crawls a client's blog and its competitors' blogs, splits pages into topic sections, embeds and clusters them by meaning, finds topics competitors cover but the client doesn't, scores each gap and produces content briefs for human writers.

Work in progress. Documentation starts at [`docs/00_PROJECT_BRIEF.md`](docs/00_PROJECT_BRIEF.md).
